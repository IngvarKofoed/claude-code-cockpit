# Released v0.53.0

Released v0.53.0, carrying the model-family chip colours
(`2026-09-16-model-family-chip-colours`). Bumped per entry 103 — the plugin cache is
keyed by version and `ensure.js` only replaces a running daemon when `/health` reports
a DIFFERENT one, so without the bump the new `modelColors` schema never reaches an
existing daemon. `marketplace.json` stays at 0.2.0, unmaintained, so it is left alone.

## Detail
- **This bump is load-bearing, not routine.** The feature fails in a specific, misleading
  way on a stale daemon: assets are served no-cache so the browser gets the new Settings
  UI, but the old `validateConfig` drops the unknown `modelColors` key, so Settings toasts
  "saved" while the Live view never changes and reopening reads "No colour". Anyone whose
  daemon predates the feature sees exactly that until this version reaches them.
