# Released v0.54.0

Released v0.54.0, carrying the group-box reordering arrows
(`2026-09-22-group-box-reordering`). Bumped per entry 103 — the plugin cache is keyed by
version and `ensure.js` only replaces a running daemon when `/health` reports a DIFFERENT
one, so a UI-only change still needs the bump to reach anyone. `marketplace.json` stays at
0.2.0, unmaintained, so it is left alone.

## Detail
- **A stale daemon is not the failure mode here, unlike v0.53.0's.** This change is entirely
  in `web/`, which the daemon serves from disk no-cache — confirmed live: the running 0.53.0
  daemon served the edited `app.js` and the feature worked against it. The bump is for the
  plugin *cache*, so a fresh install picks the new files up; an already-running daemon
  already has them.
