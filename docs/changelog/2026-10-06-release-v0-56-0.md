# Released v0.56.0

Released v0.56.0, carrying the point-release rates (`2026-10-06-opus-5-5-fable-5-1-pricing`)
and the Sonnet 5 price correction (`2026-10-06-sonnet-5-standard-price`). Bumped per entry 103 —
the plugin cache is keyed by version and `ensure.js` only replaces a running daemon when
`/health` reports a DIFFERENT one. `marketplace.json` stays at 0.2.0, unmaintained, so it is
left alone.

## Detail
- **This bump is load-bearing, like v0.53.0's.** Rates and the CONFIG_VERSION 4 migration are
  read at daemon boot, so a pre-0.56.0 daemon keeps pricing Opus 5.5 / Fable 5.1 as "—" and
  Sonnet 5 at $3/$15 until it is replaced. Unlike a `web/`-only change, nothing reaches it
  from disk.
