# Released v0.57.0

Released v0.57.0, carrying the background-shell wait (`2026-10-17-background-shell-wait`), the
test-command shells (`2026-10-17-test-command-shells`) and the vertical group track width
(`2026-10-20-vertical-group-track-width`). Bumped per entry 103 — the plugin cache is keyed by
version and `ensure.js` only replaces a running daemon when `/health` reports a DIFFERENT one.
`marketplace.json` stays at 0.2.0, unmaintained, so it is left alone.

## Detail
- **This bump is load-bearing for the two shell changes.** Both live in `emit.js` and the
  aggregator, which run from the plugin cache, so live sessions keep reading a finished test run
  as idle until v0.57.0 reaches them. Both entries call this out as unverified through the
  installed plugin. The group-width change is `web/`-only and was already live from disk.
